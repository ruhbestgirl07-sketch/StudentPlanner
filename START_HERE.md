# Start Here — Student Planner Enhanced

1. Open `StudentPlanner.sln` in Visual Studio or open this folder in VS Code.
2. Install the .NET 8 SDK if it is not already installed.
3. In a terminal at this folder, run:

   ```bash
   dotnet restore StudentPlanner.sln
   dotnet build StudentPlanner.sln
   dotnet test StudentPlanner.sln
   dotnet run --project StudentPlanner/StudentPlanner.csproj
   ```

4. Open the local URL shown in the terminal.
5. Read `StudentPlanner/README.md` for full setup and feature instructions.
6. Read `StudentPlanner/docs/requirements-traceability.md` to see the evidence needed for each of the lecturer's 20 criteria.

**Before submission:** run the build and tests on your own computer, capture the real test output, and complete the browser/device checks. This environment did not have the .NET SDK, so those commands could not be executed here.
